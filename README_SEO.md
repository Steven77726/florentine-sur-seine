# Florentine sur Seine — Projet & Optimisations SEO

Ce dossier contient l'intégralité du site public **https://florentine-sur-seine.fr/** avec toutes les optimisations SEO et réseaux sociaux appliquées.

---

## 🚀 Optimisations SEO réalisées

### 1. Page d'accueil (`index.html`)
- **Titre optimisé** : `Florentine sur Seine | Bar Festif & Péniche à Boulogne-Billancourt` (mots-clés forts et localisation).
- **Meta description** : Intègre l'activité, la localisation (92) et un appel à l'action.
- **Open Graph complet** : Aperçu riche automatique avec image (`FLO.jpg`), titre et description lors des partages sur WhatsApp, iMessage, Instagram, Facebook.
- **Twitter Card** : `summary_large_image`.
- **Données structurées Schema.org** :
  - `@type: ["BarOrPub", "EventVenue"]`
  - Adresse exacte : 52 quai du Point du Jour, 92100 Boulogne-Billancourt
  - Coordonnées GPS réelles : `48.829023`, `2.255293`
  - Téléphone WhatsApp, lien vers la carte et profil Instagram.
- **Balisage H1 sémantique** : `<h1>Florentine sur Seine — Péniche & Bar festif à Boulogne-Billancourt</h1>`.

### 2. Page Carte (`carte.html`)
- **Open Graph** : Balises sociales complètes.
- **Mots-clés de niche** : Mention explicite de la sélection de vins certifiés **Casher** (`(K)`), essentielle pour le positionnement sur les recherches qualifiées (*bar casher seine*, *soirée casher boulogne*).

### 3. Page Privatisation (`privatisation.html`)
- **Open Graph** : Balises sociales complètes.
- **FAQ visible** : Questions/réponses clés pour les utilisateurs (capacité, espaces à quai, devis).
- **Schema.org `FAQPage`** : Éligibilité aux résultats enrichis (questions déroulantes sur Google).

### 4. Page Photos (`photos.html`)
- **Open Graph** configuré avec l'image réelle de la péniche.
- **Galerie enrichie** : Photo réelle de la péniche et affiche artistique avec balises `alt` descriptives pour le référencement sur Google Images.

### 5. Pages Concept & Blog
- Balises Open Graph ajoutées sur toutes les pages pour des partages impeccables sur les réseaux.
